## How to Write

1. Create a Markdown file under `docs/`, e.g. `docs/posts/hello-world.md`.
2. Add an English version `docs/posts/hello-world.en.md` (optional; falls back to Chinese if missing).
3. Register the file in the `nav` section of `mkdocs.yml`.
4. Preview locally with `mkdocs serve` and open `http://127.0.0.1:8000`.
