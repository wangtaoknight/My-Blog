# 我的第一篇文章

> 发布日期：2026-10-19

这是新博客的第一篇文章，用于验证写作与发布流程。

## 写作方式

1. 在 `docs/` 下新建 Markdown 文件，例如 `docs/posts/hello-world.md`。
2. 为它添加一份英文版本 `docs/posts/hello-world.en.md`（可选，缺失时会回退显示中文）。
3. 在 `mkdocs.yml` 的 `nav` 中登记该文件。
4. 本地预览：`mkdocs serve`，浏览器打开 `http://127.0.0.1:8000`。

## 常用语法

- 标题：`#` 到 `######`
- 强调：`**粗体**`、`*斜体*`
- 代码块：三个反引号包裹，并标注语言
- 提示框：

!!! note "提示"
    这是 MkDocs Material 的 admonition 语法，适合写注意事项。
