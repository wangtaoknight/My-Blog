# 红楼梦

《红楼梦》，原名《石头记》，清代曹雪芹著，中国古典四大名著之一。本站收录一百二十回全文，按章回编排，便于逐回阅读。

!!! note "文本说明"
    底本为[维基文库](https://zh.wikisource.org/wiki/紅樓夢)所收公版文本（繁体）；《红楼梦》原文已进入公有领域。
